# Codable

Importa la biblioteca convert de Dart, que proporciona herramientas para convertir datos entre diferentes formatos.

```
import 'dart:convert';
```


Importa el paquete http de Dart, que permite realizar solicitudes HTTP para comunicarnos con servidores y consumir APIs

```
import 'package:http/http.dart' as http;
```

  path: ^1.9.1

    sdk: flutter

  drift_dev: ^2.35.3
  build_runner: ^2.15.1

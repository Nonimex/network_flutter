# Codable

Importa la biblioteca convert de Dart, que proporciona herramientas para convertir datos entre diferentes formatos.

```
import 'dart:convert';
```


Importa el paquete http de Dart, que permite realizar solicitudes HTTP para comunicarnos con servidores y consumir APIs

```
import 'package:http/http.dart' as http;
```

# DRIFT 

- importar las dependecias en archivo PUBSPEC.YAML

```

dependencies:
  drift: ^2.35.4
  drift_flutter: ^0.3.1
  path_provider: ^2.1.6
  provider: ^6.1.5+1
  path: ^1.9.1

  flutter:
    sdk: flutter
 
dev_dependencies:
  drift_dev: ^2.35.3
  build_runner: ^2.15.1
```

de DRIFT (  
*provider: ^6.1.5+1
*path: ^1.9.1)


de Pub (
dependencies:

  -drift: ^2.35.4
  -drift_flutter: ^0.3.1
  -path_provider: ^2.1.6



dev_dependencies:
  -drift_dev: ^2.35.3
  -build_runner: ^2.15.1
  
)


- Para ejecutar y generar el archivo .g automatico en la terminal se puso: dart run build_runner build
